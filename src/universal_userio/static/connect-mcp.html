Подключите UserIO к своему ИИ

Полностью бесплатно. Bearer-токен подходит для ZCode и других MCP-клиентов без OAuth. Каждый токен открывает только ваш UserIO и действует, пока вы его не отзовёте.

Подключение MCP не отправляет каждое новое сообщение.

MCP-клиент обращается к UserIO по запросу. Для автоматической передачи входящих в Agent Herder нужен отдельный HTTPS webhook-приёмник. MCP-токен не является адресом этого приёмника.

Сначала попросите владельца Agent Herder дать URL приёмника и сказать, где безопасно сохранить одноразовый ключ. Затем войдите в кабинет и откройте настройки «Передача новых сообщений».

Войти в кабинет · Как передавать новые сообщения

1. Создайте токен

Войдите в личный кабинет, затем вернитесь на эту страницу.

Выберите платформы, аккаунты и права. Для каждого чата можно разрешить чтение или чтение и запись. Невыбранные чаты недоступны.

Скопируйте сейчас — повторно токен не показывается.

2. Добавьте MCP в свой клиент

Адрес: https://msg.bezrabotnyi.com/mcp

Выберите HTTP / Streamable HTTP и авторизацию Bearer token. Вставьте свой токен в поле токена. Если клиент предлагает заголовки, укажите:

Authorization: Bearer ВАШ_ТОКЕН

OAuth и регистрация приложения для этого способа не нужны. Не вставляйте токен в чат с ИИ. Формат настроек зависит от клиента.

Первая проверка: «Через UserIO покажи мои подключённые аккаунты». При необходимости обновите список инструментов.

Codex CLI
export USERIO_BEARER_TOKEN='ВАШ_ТОКЕН'
codex mcp add UserIO --url https://msg.bezrabotnyi.com/mcp --bearer-token-env-var USERIO_BEARER_TOKEN

Для постоянного запуска используйте защищённую настройку переменной окружения своего клиента.

Если клиент поддерживает OAuth, можете выбрать его и войти в UserIO через браузер — оба способа работают независимо.

Ваши токены
