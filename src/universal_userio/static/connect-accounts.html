Подключить аккаунт

Выберите сервис → Подключите → Проверьте

Matrix

  1. Укажите адрес своего Matrix-сервера.
  2. Нажмите «Войти через SSO» или введите Matrix ID и пароль.
  3. Проверьте подключённый профиль и откройте сообщения.

Для SSO Matrix ID можно не указывать: определим его после входа.

Или подключите аккаунт по паролю / токену:

Есть готовый access token вместо пароля?

Укажите пароль или токен, не оба сразу.

После входа проверяем Matrix ID через сервер. Существующие аккаунты других пользователей не меняются.

Другая почта

  1. Разрешите IMAP в настройках ящика.
  2. Создайте пароль приложения для почты.
  3. Введите адрес и пароль — проверим доступ.

Настройки сервера

IMAP только через TLS. Письма загружаются без установки отметки «прочитано». Отправка SMTP пока не подключается.

ВКонтакте

  1. Нажмите «Войти через VK Мессенджер» и подтвердите свой аккаунт.
  2. Скопируйте итоговый адрес из адресной строки и вставьте ниже.
  3. Нажмите «Проверить и подключить».

Одноразовая авторизация, затем история и новые сообщения синхронизируются с сервера UserIO. Chrome или расширение постоянно держать открытыми не нужно.

Войти через VK Мессенджер ↗

После подтверждения входа скопируйте полный адрес итоговой страницы oauth.vk.ru/blank.html из адресной строки и вставьте ниже. Поддерживаются оба ответа VK: токен и одноразовый результат входа. Если VK не дал доступ к сообщениям, UserIO сообщит об этом и не подключит пустой аккаунт. Не пересылайте адрес или токен в переписку.

Проверить конкретный VK ID

UserIO самостоятельно проверит личные диалоги и историю. Если VK не разрешит чтение, аккаунт не будет помечен подключённым. Ваш текст отправляется из личного аккаунта через кнопку в диалоге. Предложения ИИ требуют подтверждения. Отметки о прочтении не отправляются.

Telegram

  1. Откройте Telegram на телефоне.
  2. Перейдите в «Настройки → Устройства → Подключить устройство».
  3. Запустите вход и отсканируйте QR-код. Если включён облачный пароль, введите его в форме.

Новый аккаунт должен появиться здесь после подтверждения.

WhatsApp

  1. Откройте WhatsApp на телефоне.
  2. Выберите «Настройки → Связанные устройства → Привязка устройства».
  3. Отсканируйте QR-код своего подключения.

Каждому пользователю нужен отдельный подключённый мост WhatsApp.

Самостоятельное подключение нового пользователя пока не готово. Администратор должен выдать отдельный мост вашему аккаунту; общий QR сервера для этого не подходит.

Инструкция и настройка моста

MAX

  1. Откройте MAX на телефоне, в котором уже выполнен вход.
  2. Нажмите «Показать QR-код». В MAX выберите «Профиль → Устройства → Подключить устройство».
  3. Отсканируйте QR-код и подтвердите вход на телефоне. Проверим профиль и сохраним его в вашем UserIO.

SMS на Android

  1. Установите SMS Agent APK. Подойдёт Android 8+ с root или без него.
  2. Разрешите SMS и работу приложения в фоне. Скопируйте ID устройства.
  3. Получите настройки своего телефона, вставьте их в приложение и запустите.

Звонки через SIM

  1. Подготовьте совместимый Android с root и GSM2SIP.
  2. Получите свой SIP-аккаунт у администратора.
  3. Подключите маршрут звонков к своему UserIO и проверьте звук.

SMS APK не подключает голосовые звонки. Для звонков нужна отдельная настройка шлюза.
