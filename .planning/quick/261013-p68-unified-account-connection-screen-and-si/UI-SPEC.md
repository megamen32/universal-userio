# One account screen

One entry from the inbox: «Аккаунты». Existing accounts first, then a compact
provider grid. Choose one service: the grid yields to one setup panel with
«Все аккаунты» / «К сообщениям», three short steps and a single primary action.
Successful connection stays here with connected identity and «Открыть сообщения»
or «Подключить ещё». Back/reload keep the selected service. Credentials never in
URLs/history/storage. Existing provider callbacks preserve their query before
canonical navigation. No parallel panels, auto-started login, or status based on
message silence. Advanced tokens/server fields collapsed, mail presets automatic.
Dark existing UserIO palette, blue primary, 16px body, 24px heading, 12px corners,
44px tap targets, keyboard focus, <=780px content, one column below600px.
Provider limitations visible before login; unsupported enrollment is not success.
