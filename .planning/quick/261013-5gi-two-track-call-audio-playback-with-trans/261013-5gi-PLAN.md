Сохранить существующий recorder без повторных звонков. Доступ к реальным received/sent WAV — только через существующий разговор текущего пользователя. В завершённом звонке показать две подписанные дорожки с общей шкалой, прослушиванием и скачиванием, рядом с существующей расшифровкой.

1. Проверить native архив и immutable call/account/peer связь.
2. Добавить ограниченный authenticated WAV range endpoint и metadata карточки.
3. Проверить focused integration (expected 5s, maximum30s): ownership, WAV directions/alignment, incomplete capture, byte ranges. Затем build (expected15s, maximum120s) через штатный профиль.
4. Опубликовать/установить owned source; проверить настоящий recorded call через managed headed44 UI, оба аудио и reload. Не звонить повторно, не менять voice runtime.
