# UserIO: три контейнера и исправление боковой панели

frontend, backend со всеми каналами и voice. В production работают ровно эти
три контейнера; старые постоянные UserIO host units отключены. Сохранён только
конечный native phone-lease oneshot без постоянного процесса. Общие платформы,
физический телефон и краткие SSH-чтения архива остаются внешними зависимостями.
