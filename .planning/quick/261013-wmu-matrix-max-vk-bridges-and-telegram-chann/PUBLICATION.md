# Публичное оформление Matrix-моста MAX/VK

Дата: 2026-10-14. По прямому поручению владельца публикуется компонент
существующего публичного репозитория megamen32/universal-userio, без нового checkout.

Добавлены русское руководство установки, пример регистрации Application Service,
CONTRIBUTING, CHANGELOG и лицензия MIT, явно ограниченная файлами компонента MAX/VK.
Примеры не зависят от имени локального пользователя и адреса личного сервера.
README проекта и каталог документации ссылаются на мост.

CI: один GitHub Actions job, Python 3.10 и 3.12, общий wall 180 секунд.
Actions закреплены по точному commit. Прогоны последовательные, каждый wall 30 секунд,
MemoryHigh/Max 96/192 МиБ, swap 0, CPU 50%, Tasks 32, IOWeight 25,
LimitNOFILE 128, LimitFSIZE 16 МиБ. Live account integration в публичном CI не запускается.

Проверки перед публикацией:
- 29 модульных проверок успешны; повтор с теми же cgroup-ограничениями CI — 6.558 секунды.
- Примеры JSON/YAML разбираются, namespace сопоставляется только с ghost-префиксом,
  локальные ссылки руководства существуют, git diff --check успешен.
- В публикуемые пути не включены runtime config, SQLite, токены или canary evidence.
- Чужие изменения Telegram call transport сохраняются без включения в коммит.

Изменены только документация, шаблоны и CI. Действующие сервисы не перезапускались.
Прежняя проверка доставки MAX/VK (12/12) остаётся в VK-MAX-SUMMARY.md.
Решение по удалению исторических дублей не входит в поручение о публикации.
