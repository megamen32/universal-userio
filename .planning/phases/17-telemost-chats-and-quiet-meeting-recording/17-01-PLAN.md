# Telemost meeting links and recordings

User mandate: a link sent to the Secretary joins a meeting quietly, records all
received voices, and produces a persistent transcript in UserIO. Meeting chat
belongs to the same source. Existing business/native Secretary work is independent.

1. Reuse WhiteTransport's verified connection/WS/subscriber protocol without its
   VPN tunnel, video publisher, auth-cookie copying or TLS-verification bypass.
2. Durable owner-scoped start/get/stop; request IDs never cause an uncertain join
   to replay. Trackless publisher negotiation, no local mic/camera tracks.
3. Bounded remote recorder44, per received audio track, honest identity/mixed
   labels, private audio bytes, automatic transcription and ordinary inbox view.
4. HTTP/MCP and web link/status/stop/player; discover meeting chat using actual
   connection metadata, never guess author identity or advertise unsupported send.
5. Focused integration, publish exact source, scoped install, then one real
   user-authorized link acceptance and audio/transcript/reload/cleanup proof.
