# Android SMS adapter

Started at 2026-09-01T18:50:28+03:00 (manual clock)
Cycle estimate: minimum 20 / maximum 45 active minutes.

## Минимальный путь

1. Результат: Android SMS Gateway появляется в Universal UserIO как канал `sms`: новые SMS видны как диалоги, ответ остаётся черновиком до явного подтверждения и затем уходит через Android.
2. Короткий реальный canary: на изолированном локальном gateway входящее SMS синхронизируется в UserIO, черновик подтверждается, а gateway получает строго авторизованный запрос отправки без реальной отправки оператору.
3. YAGNI-срез: один конфигурируемый gateway, один владелец UserIO, текстовые SMS без вложений, pull-синхронизация при открытии канала.

## Не делаем сейчас

Многосимочные аккаунты, хранение gateway-ключей в БД, MMS/вложения, фоновый polling/очередь, гарантии доставки у оператора и UI-мастер настройки.

## Результат

`main` содержит адаптер и его сквозной тест. Live-включение намеренно не делалось: действующий `/opt/universal-userio` имеет чужие незакоммиченные изменения и не может быть безопасно обновлён поверх них. После чистой интеграции production checkout нужно добавить приватные `USERIO_SMS_GATEWAY_*` переменные и перезапустить оба сервиса.
