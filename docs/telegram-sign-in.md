# Вход в Telegram

Подключайте Telegram из экрана аккаунтов под своим личным входом UserIO.
Можно отсканировать QR-код или войти по номеру, затем ввести код и, если
включён, облачный пароль. Сервисный токен чтения не даёт права подключать аккаунты.

Формы телефона, кода и пароля используют обычную urlencoded-передачу:
это тот же формат, который читает сервер. Пароль не нужно присылать в чат.
При подключении того же Telegram-аккаунта UserIO сохраняет его identity
и переводит привязку на новую сессию; история и задачи не создаются заново.

«Аккаунт подключён» и начавшаяся синхронизация означают успешный вход.
Первое сканирование старых диалогов может продолжаться, пока свежие сообщения
уже доступны. Сохранённый кэш можно читать и без живого подключения;
автоматическое обновление задач требует отдельно подтверждённой свежести.

Если Telegram отозвал вход, подключите аккаунт заново. Уже отправленные
сообщения и действия с неизвестным исходом автоматически не повторяются.
