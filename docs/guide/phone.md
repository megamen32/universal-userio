# Android: SMS с root и без root

## Подключить свой телефон

[Откройте форму подключения](https://msg.bezrabotnyi.com/connect-phone). Инструкция доступна всем; настройки выдаются после входа в **ваш** кабинет.

1. [Скачайте SMS Agent APK](https://msg.bezrabotnyi.com/sms-gateway/agent/download) для Android 8+. Разрешите установку из браузера и откройте приложение.
2. Разрешите SMS, уведомление службы и работу в фоне. Отключите оптимизацию батареи/ограничения автозапуска для приложения.
3. Скопируйте ID устройства из приложения в форму сайта; укажите название телефона.
4. Введите полученные адрес шлюза и **отдельный токен устройства** в приложение. Нажмите «Сохранить и запустить».
5. Дождитесь статуса подключения и откройте SMS этого телефона в UserIO. Сверьте входящее сообщение. Отправка использует вашу SIM и её тариф.

Тот же APK работает на rooted и unrooted Android. Токен привязан к одному телефону и пользователю, не является общим ключом сервиса. Повторная выдача заменяет только токен выбранного подключения.

## Что синхронизирует APK

Новые и доступные приложению недавние **входящие** SMS; ответы, отправленные через UserIO, остаются в его истории. Полный архив и исходящие из других приложений этот APK пока не импортирует.

Сайт не должен быть открыт для работы службы. После потери сети приложение и шлюз повторяют доставку; ID сообщений помогают не создавать дубли. Неизвестный исход отправки не повторяйте вслепую.

## Полный архив rooted Android

Есть отдельный операторский native-маршрут через системное SMS-хранилище: входящие, исходящие и постоянный курсор, включая переход outbox→sent. Он требует установки и привязки **вашего** телефона; чужой уже подключённый телефон не является общим источником для новых пользователей.

GSM2SIP-журнал и очереди SIP MESSAGE не заменяют полный системный архив. [Техническая инструкция SMS](https://github.com/megamen32/universal-userio/blob/main/docs/SMS.md).

## Отключить

**Добавить аккаунт → Ваши подключения → Отключить** у телефона, затем остановите приложение. Старый токен не разрешает новые операции; история остаётся.

Звонки подключаются отдельно: [GSM2SIP и SIP/AgentCall](calls.md).
