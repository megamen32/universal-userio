# Matrix

## Сообщения и звонки — разные возможности

Matrix входит в универсальный шлюз UserIO наряду с Telegram, Телемостом и
сотовой связью. Описанное ниже подключение inbox предназначено для чтения.
Отдельный голосовой маршрут MatrixRTC существует в UserIO, но требует
настроенного RTC-backend, доступной комнаты, нужного аккаунта и явного согласия
на конкретный звонок. Наличие read-only аккаунта не включает его автоматически.
Для уведомлений/вопросов агентов канал выбирает Notice Place, а звонок выполняет
UserIO. Asterisk и Android для MatrixRTC не являются обязательной цепочкой.
[Обзор звонков](calls.md) · [Архитектура](architecture.md).

## Подключить свой аккаунт

Выберите **Добавить аккаунт → Matrix**. Укажите HTTPS-адрес homeserver и свой Matrix ID. Форма поддерживает пароль, одноразовый SSO login token либо существующий access token. Секрет вводится только в форме вашего подключения.

UserIO проверяет реальную Matrix-идентичность, связывает комнаты с вашим пользователем и хранит отдельный sync-курсор. Для другой учётной записи создайте отдельное подключение.

## Проверить

Откройте известную комнату и сравните автора, время и текст. Поддерживаемое пользовательское подключение предназначено для **чтения**: отправка и поддержка зашифрованных комнат этим действием не обещаются.

## Собственный сервер

Доступные пользователям homeserver должны удовлетворять проверке адреса коннектора. Для доверенного собственного homeserver с split-horizon DNS оператор может указать точное имя в `USERIO_MATRIX_TRUSTED_HOSTS`; это не универсальное разрешение любых адресов.

[Развёртывание](self-host.md) · [Контракты коннекторов](https://github.com/megamen32/universal-userio/blob/main/deploy/INSTALL.md#multi-user-account-linking).

## Отключить

В «Ваши подключения» отключите выбранный аккаунт. Его синхронизация и сохранённый секрет прекращаются; импортированные сообщения сохраняются.
