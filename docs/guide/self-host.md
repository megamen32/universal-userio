# Развернуть на своём сервере

## Подготовьте окружение

Для текущего HTTP runtime со встроенным Fast Agent используйте Python 3.12+. Библиотека stdlib-адаптеров и metadata пакета допускают Python 3.10+, но это не заменяет требования установленного Fast Agent 0.10.43. Зависимости каналов ставятся отдельно.

```bash
git clone https://github.com/megamen32/universal-userio.git
cd universal-userio
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[fast-agent]'
```

Для нужного канала установите соответствующее дополнение, например:

```bash
python -m pip install -e '.[telegram]'
```

## Задайте конфигурацию

Используйте `.env.example` как перечень настроек. Настоящие секреты храните вне Git с ограниченными правами. Для владельца предусмотрен отдельный seed-файл с именем пользователя и паролем.

Секреты должны быть переданы в окружение процесса или штатный механизм загрузки. Само создание файла с произвольным именем не настраивает службу.

## Запустите HTTP-сервис

При настроенном окружении:

```bash
python -m universal_userio.runtime
```

Проверенная конфигурация по умолчанию слушает `127.0.0.1:18093`. В systemd-развёртывании используются файлы из `deploy/` и отдельные постоянные каталоги состояния.

## Подключите транспорт

Запуск HTTP API не запускает все каналы автоматически. Telegram и WhatsApp используют отдельные коннекторы; почте нужен воркер; VK зависит от браузерного расширения; MAX настраивается своим ingress-процессом.

Для каждого канала проверьте привязку аккаунта к пользователю, входящее сообщение и исходящий маршрут. Начните без автоматической отправки.

## Опубликуйте HTTPS

Поставьте перед локальным сервисом reverse proxy с HTTPS. Он должен корректно передавать `Host` и `X-Forwarded-Proto`. OAuth discovery и `/mcp` должны быть доступны снаружи по одному согласованному адресу.

Не отключайте авторизацию API ради работы лендинга или документации. Публичная статика и приватные данные обслуживаются разными маршрутами.

## Обновляйте с возможностью отката

Для рабочего сервера используйте штатный `scripts/runtime_release.py` и [инструкцию развёртывания проекта](https://github.com/megamen32/universal-userio/blob/main/deploy/INSTALL.md). Процедура включает зафиксированную версию, манифест, резервную копию управляемых файлов, проверку и canary.

Храните базу, сессии каналов и секреты отдельно от кода. Перед обновлением проверьте резервные копии и ресурсные ограничения. Не заменяйте рабочее дерево командами, которые удаляют чужие незакоммиченные изменения.
