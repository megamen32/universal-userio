# Выберите канал

| Канал | Начать | Чтение и отправка |
| --- | --- | --- |
| [Telegram](telegram.md) | Личный кабинет → Telegram → вход по QR | История и новые сообщения, отдельные аккаунты, отправка при наличии reply |
| [Gmail](gmail.md) | Аккаунты → Gmail, пароль приложения | Новый пользовательский IMAP — чтение; отправка требует отдельного SMTP-маршрута |
| [Яндекс и другая почта](yandex.md) | Аккаунты → Почта IMAP | Входящие по IMAP; SMTP не подключается автоматически |
| [Matrix](matrix.md) | Аккаунты → Matrix | Пользовательское подключение для чтения |
| [MAX](max.md) | Авторизованный коннектор, настройка оператора | Новые сообщения, ограниченная история, отправка и повторное редактирование своих сообщений |
| [WhatsApp](whatsapp.md) | Отдельный мост Baileys, связанное устройство | Доступность операций зависит от настроенного моста |
| [VK](vk.md) | Одноразовый вход в VK Мессенджер и закрытая форма User.io | Личная история, новые сообщения, отправка текста/фото/документов до 2 МБ и повторное редактирование своих сообщений |
| [Android SMS](phone.md) | Подключить телефон → SMS Agent APK | Root не нужен; новые/недавние входящие, отправка через свою SIM |
| [Голосовые звонки](calls.md) | Отдельные возможности Telegram, MatrixRTC и SIM-аккаунта | Права и голосовой транспорт проверяются отдельно от чтения сообщений; GSM2SIP требуется только сотовому маршруту |
| [Телемост](../telemost.md) | Ссылка на разрешённую встречу | Видимое подключение, поддерживаемая запись и расшифровка; допуск и согласие на запись отдельно |
| ChatGPT | Отдельный локальный CDP-коннектор оператора | Зависит от установленного адаптера; не подключается одним MCP-адресом |

## Начать переписку с новым контактом

Контакт, которого ещё нет в истории, открывается через `userio.contacts.resolve`
и `userio.contacts.start` — это тот же путь отправки, что и у готовых чатов.
Что доступно по каналам:

| Канал | Идентификатор | Особенности |
| --- | --- | --- |
| [Telegram](telegram.md) | `@username`, номер телефона | Ник резолвится коннектором в peer id. Номер телефона Telegram резолвит только после импорта контакта: в аккаунте появится контакт с именем UserIO |
| [Gmail](gmail.md) | адрес почты | Первое письмо уходит без `In-Reply-To`; ответ приходит в тот же чат |
| [Android SMS](phone.md) | номер телефона | Чат создаётся по нормализованному адресу, отправка идёт через ту же SIM |
| [VK](vk.md) | профиль, ссылка или ID | Peer резолвится через `users.get`; профиль должен принимать личные сообщения |
| [Яндекс и другая почта](yandex.md) | ID пользователя или ссылка Телемоста | Peer резолвится существующим оператором Яндекса |
| [MAX](max.md) | — | У клиента MAX нет резолва по телефону: нужен готовый `chat_id` |
| [WhatsApp](whatsapp.md) | номер телефона | Отправка недоступна, пока у аккаунта нет права `reply` |
| [Matrix](matrix.md) | MXID | Отправка недоступна, пока у аккаунта нет права `reply` |
| ChatGPT | — | У канала нет внешних контактов |

Если канал не умеет резолвить идентификатор, инструмент отвечает честной
ошибкой `contact_resolution_unsupported:<канал>` и ничего не отправляет.

## Несколько аккаунтов

Подключайте каждый аккаунт отдельно и называйте его понятно: «Почта продаж», «Рабочий Telegram». Идентичность определяется устойчивым ID, а не отображаемым именем. Собеседник с одним номером на двух телефонах не смешивает их истории.

## После подключения

Сверьте последнее сообщение, направление, автора, время и исходящий аккаунт с оригиналом. В Telegram и MAX групповые сообщения показывают имя автора и username, если провайдер его передал. При отсутствии имени показывается честный ID, а не выдуманный человек.

Проверьте возможности выбранного аккаунта: `read` не означает `reply`. Поддержка вложений, редактирования и глубина истории зависят от адаптера. [Ограничения и ошибки](troubleshooting.md).


## Одно место для подключений

Откройте [Аккаунты](https://msg.bezrabotnyi.com/accounts) из боковой панели. Здесь показаны ваши текущие
подключения и выбор сервиса. Нажмите название, выполните три коротких шага и
проверьте результат. Gmail и Яндекс получают настройки сервера автоматически;
для другой почты раскройте «Настройки сервера». Дополнительные токены и методы
входа спрятаны под пояснением. После успешного подключения можно открыть
сообщения или добавить ещё один аккаунт.

MAX подключается по QR прямо в разделе «Аккаунты». Выдача SIP-аккаунта для звонков пока требует администратора.
Это явно показано до ввода данных; открытая сессия в приложении не считается
подключением к UserIO. Для WhatsApp нужен отдельный мост на пользователя.
