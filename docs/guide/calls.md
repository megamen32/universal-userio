# Звонки: отдельная установка

SMS Agent не включает голосовые звонки. Для SIM-звонков нужен совместимый rooted Android, GSM2SIP с подходящим аудиопрофилем, SIM с голосовым тарифом, питание, интернет и настроенный SIP/Asterisk.

## Подготовить устройство

1. Изучите [GSM2SIP](https://github.com/pulpoff/gsm2sip) и [APK/Magisk releases](https://github.com/pulpoff/gsm2sip/releases). Проверяйте модель и прошивку: root сам по себе не гарантирует рабочий звук.
2. Установите совместимый вариант, предоставьте разрешения и фоновую работу. Magisk-модуль может требовать перезагрузки.
3. Откройте [Аккаунты → Звонки](https://msg.bezrabotnyi.com/accounts?service=calls), укажите название и постоянный ID телефона и получите личные SIP-настройки нашего сервера. Введите их в GSM2SIP. SMS-токен не является SIP-паролем.
4. Нажмите «Обновить статус телефона» в UserIO. Выдача настроек и SIP-регистрация ещё не означают рабочие звонки: персональный голосовой маршрут и события должны быть привязаны к **вашему** аккаунту, затем проверен звук. До этой проверки звонки по новому подключению остаются выключены.
5. На согласованном тестовом номере проверьте регистрацию, звук в обе стороны, видимый номер, начало и завершение звонка.

## Как выглядит история

Звонки одному номеру на одном аккаунте объединяются в один диалог. «Звонок начат», «Звонок завершён» и записи разговора остаются отдельными событиями. Старые записи без доказанного номера не назначаются текущему собеседнику; они могут оставаться в архиве.

## Без root

Обычный Android с одним SMS APK не даёт SIM-аудио шлюзу. Для звонков используйте отдельно поддерживаемый SIP/телефонию либо совместимое устройство. Личный SIP-аккаунт выдаётся отдельно в разделе «Аккаунты → Звонки»; форма SMS выдаёт настройки SMS Agent.
