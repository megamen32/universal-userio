# Передача новых сообщений

## Выберите нужный способ

Подключение ИИ через MCP позволяет клиенту обращаться к UserIO по запросу. Оно само по себе не отправляет каждое новое сообщение в Agent Herder.

Чтобы передавать событие при новом входящем в Agent Herder, используйте webhook. Это отдельная настройка в личном кабинете UserIO. MCP-токен не является адресом webhook-приёмника.

## Что подготовить

Попросите владельца Agent Herder дать публичный HTTPS-адрес совместимого webhook-приёмника и заранее сказать, где безопасно хранить ключ подписи. Не отправляйте этот ключ в чат и не вставляйте его в настройки MCP.

Затем войдите в UserIO, откройте настройки и выберите **«Передача новых сообщений»**. Укажите адрес приёмника. Текст переписки по умолчанию не передаётся; включайте его только если получателю он действительно нужен. UserIO передаёт только новые входящие сообщения из чатов, разрешённых правилами обработки; старые сообщения не выгружаются.

Новый ключ подписи показывается один раз после сохранения. Скопируйте его сразу в защищённые настройки приёмника. Перед включением событий убедитесь, что владелец приёмника сохранил ключ.

Полный контракт заголовков, подписи, повторной доставки и примеры событий см. в [технической справке по webhook](https://github.com/megamen32/universal-userio/blob/main/docs/incoming-webhooks.md) и в раскрываемом блоке **«Техническая настройка приёмника и проверка подписи»** в кабинете UserIO.
