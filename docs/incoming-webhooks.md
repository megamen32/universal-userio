# Webhook для новых входящих

В UserIO откройте настройки и выберите **«Действие при новом сообщении»**. Укажите HTTPS-адрес получателя, включите отправку и нажмите **«Сохранить»**. Старые сообщения при подключении не выгружаются. Кнопка **«Проверить связь»** отправляет только тестовое событие.

UserIO принимает только публичные HTTPS-адреса на порту 443. Адреса с логином, паролем, query-параметрами, частными IP и перенаправлением не поддерживаются. Для каждого входящего события используется подписанный запрос. Секрет подписи показывается один раз при создании или перевыпуске; сохраните его у получателя.

По умолчанию текст переписки не уходит. В событие входят источник, аккаунт, ID сообщения и чата, отправитель и время. Если включить **«Включать текст сообщения»**, UserIO добавит текст, максимум 8000 символов. Отправляются только входящие из чатов, разрешённых правилами автоматической обработки UserIO. Отключение webhook прекращает отправку и не ставит события в очередь для будущей доставки.

## Проверка подписи

Тело запроса — UTF-8 JSON со схемой `userio.inbound-message.v1`. Для новых сообщений заголовки:

- `X-UserIO-Event: message.received`
- `X-UserIO-Timestamp: <unix time>`
- `X-UserIO-Signature: sha256=<hex HMAC>`
- `Idempotency-Key: <event_id>`

Подпись вычисляется как HMAC-SHA256 от байтов `timestamp + "." + raw_request_body`, используя секрет, показанный UserIO. Сравнивайте подписи в постоянное время и отклоняйте слишком старые timestamp. При повторной доставке `Idempotency-Key` остаётся тем же, поэтому получателю следует дедуплицировать события по этому заголовку. Повторы выполняются с растущей задержкой до 30 минут, пока получатель не вернёт HTTP 2xx.

Проверочная отправка использует `X-UserIO-Event: webhook.test` и схему `userio.webhook-test.v1`; она не содержит сообщения из переписки.

Пример события:

```json
{
  "schema": "userio.inbound-message.v1",
  "event_id": "<stable-id>",
  "event": {
    "seq": 42,
    "source": "telegram",
    "account_ref": "telegram:123",
    "message_id": "<provider-message-id>",
    "conversation_id": "<userio-conversation-id>",
    "sender": "Алиса",
    "received_at": 1792287375.2,
    "sender_is_bot": false,
    "text": "Привет",
    "text_truncated": false
  }
}
```

Интеграция с Agent Herder настраивается как обычный webhook, если выбранный получатель предоставляет совместимый HTTPS endpoint. UserIO отправляет стандартный JSON с HMAC-подписью и не обращается напрямую к MCP-инструментам Agent Herder.
