# Записи телефонных звонков с резервного сервера44

`userio-agentcall-archive-ingress.service` на сервере100 автоматически читает
завершённые записи с44 через существующий SSH аккаунта `roomhacker`.
Нового аккаунта, ключа, звонка или распознавания этот процесс не создаёт.

После COMPLETE записи и штатной расшифровки процесс переносит обе WAV дорожки,
текст и timeline в существующий приватный архив AgentCall. Только после проверки
UUID, аккаунта, собеседника, формата WAV и атомарного появления папки публикует
сообщение «Звонок завершён» через обычный UserIO ingress. В истории пользователя
работают прежние два плеера, расшифровки под ними и авторизованное скачивание.

Сообщение имеет стабильный идентификатор по UUID звонка. Прерывание HTTP после
переноса файлов повторяет тот же приём сообщения; завершённые записи не
копируются повторно. Исходные записи44 сохраняются. Коллизия с чужой локальной
папкой не разрешается перезаписью. Незавершённые записи ждут следующего прохода.

Настройка сервиса: `USERIO_ARCHIVE_SSH_HOST=192.168.2.5`,
`USERIO_ACCOUNT_ID=phone100`, прежний `/etc/universal-userio.env` для ingress.
Чтение SSH использует прежние known_hosts/ключи, без их копирования. На44 нет
нового демона или checkout; короткая read-only Python операция приходит на stdin.

Бюджет100: RAM128MiB/high и256MiB/max, swap0, CPU0.5,32tasks, IOWeight10.
Прежде установки real двухархивный проход занял1.85s, peakRSS21.1MiB.
Один перенос ограничен120s/512MiB, JSON2MiB, до4096 папок источника,
до8 новых архивов за проход; интервал15s. Дополнительный архив ограничен5GiB
и сохраняет20GiB свободного диска; превышение откладывает перенос, без удаления.
Temporary staging ограничен одним архивом. Checkpoint содержит до10000 UUID.

Проверки: fast unit — отказ inbox после атомарного переноса/возобновление без
копий, неверный WAV, частичный tar и сохранение чужой папки; expected2s/max20s.
Focused integration — реальные completed44 архивы, обе дорожки/расшифровки,
повторный проход0new; expected3s/max30s. Source proof сам по себе не заменяет
проверку авторизованной истории и воспроизведения в установленном UserIO.
