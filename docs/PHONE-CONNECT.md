# Подключение своего Android: SMS и звонки

Откройте [инструкцию и форму подключения](https://msg.bezrabotnyi.com/connect-phone).
Она доступна без регистрации; для выдачи настроек войдите в **свой** личный кабинет.
В кабинете инструкция находится в «Добавить аккаунт → Android» и под разделами SMS и звонков.

## SMS — Android 8+ с root и без root

1. [Скачайте UserIO SMS Agent APK](https://msg.bezrabotnyi.com/sms-gateway/agent/download).
   Разрешите браузеру установку APK, установите и откройте приложение.
2. Через «Разрешения SMS» разрешите чтение, получение и отправку SMS.
   Разрешите уведомление службы, отключите оптимизацию батареи и ограничения автозапуска.
   Приложению не требуется root.
3. Скопируйте **ID устройства** из приложения (например `android-1234abcd`).
   Это ID установки приложения, а не IMEI или номер SIM.
4. В форме на сайте укажите этот ID и название телефона. Получите адрес шлюза и
   отдельный токен устройства. Вставьте их в приложение и нажмите «Сохранить и запустить».
5. Дождитесь статуса «подключён к UserIO». Откройте SMS-аккаунт этого телефона в кабинете.
   Проверьте одно входящее сообщение и отправку на собственный тестовый номер.
   Отправка использует SIM и оплачивается по её тарифу.

Rooted Android использует тот же APK и ту же форму. APK передаёт новые входящие и
недавние доступные ему входящие сообщения. Полный архив и SMS, отправленные из других
приложений, этим APK пока не синхронизируются. Отправленные через UserIO сохраняются
в его истории. Не путайте этот путь с отдельным native-подключением оператора.

Повторная выдача настроек заменяет токен только выбранного телефона этого пользователя.
Токен показывается один раз и не является ключом UserIO или администратора.
Для отключения откройте «Добавить аккаунт → Ваши подключения», нажмите «Отключить»
у SMS-аккаунта телефона и остановите приложение. Сохранённая история остаётся;
старый токен больше не разрешает новые операции отключённого аккаунта.

### Полный SMS-архив на rooted Android

Это операторская установка [native Android SMS gateway](https://github.com/megamen32/android-sms-gateway),
с разрешённым доступом к системному SMS-хранилищу и собственной привязкой пользователя.
Нынешняя native-конфигурация S21 обслуживает один настроенный телефон, а не произвольные
телефоны новых пользователей. Для другого телефона нужен свой настроенный шлюз и маршрут;
копировать доступ или привязку существующего S21 нельзя. Проверьте входящие и исходящие,
полное тело SMS, восстановление после потери сети и курсор постоянной синхронизации.

## Звонки — отдельная установка GSM2SIP и SIP/AgentCall

SMS Agent не подключает звонки. Для SIM-звонков нужны совместимый rooted Android,
подходящий аудиопрофиль, SIM с голосовым тарифом, питание, интернет и SIP/Asterisk.
Root сам по себе не гарантирует совместимость аудио.

1. Изучите [GSM2SIP и проверку совместимости](https://github.com/pulpoff/gsm2sip).
   [APK и Magisk-модуль](https://github.com/pulpoff/gsm2sip/releases) распространяются отдельно
   от SMS Agent. Следуйте инструкции именно для своей модели и прошивки.
2. Установите подходящий вариант; обеспечьте разрешения и фоновую работу.
   Установка Magisk-модуля может потребовать перезагрузки.
3. Администратор выдаёт отдельный SIP-аккаунт: сервер, порт, имя, пароль и маршруты
   входящих/исходящих SIM-звонков. Настройте GSM2SIP и проверьте регистрацию.
   Токен SMS Agent не является SIP-паролем.
4. Администратор подключает события AgentCall к **вашему** UserIO phone-аккаунту.
5. Проверьте согласованный звонок на свой тестовый номер: звук в обе стороны,
   видимый номер, начало и завершение в UserIO. Повторные звонки этому номеру
   должны попадать в один диалог, сохраняя отдельные события каждого звонка.

На размещённом сайте голосовой сервер настраивает администратор. Самостоятельной
выдачи SIP-аккаунта через форму SMS нет. На Android без root SMS доступны через APK;
эта инструкция не обещает передачу обычного SIM-аудио без подходящего голосового шлюза.

### Контракт для администратора своей установки

- Создайте phone-аккаунт через `POST /v1/accounts` **под авторизацией его пользователя**:
  `id`, `provider: "phone"`, `display_name`, `can_read: true`, `can_reply: false`.
- Авторизацией владельца сервиса назначьте ему маршрут через `POST /v1/channel-routes`:
  `{"user":"<user_id>","source":"phone","route_id":"phone"}`.
- В его отдельном экземпляре AgentCall ingress задайте `USERIO_URL`,
  защищённый `USERIO_BEARER_TOKEN`, `USERIO_ACCOUNT_ID` этого phone-аккаунта,
  `USERIO_PHONE_ROUTE_ID=phone` и приватный `AGENTCALL_RPC_SOCKET` своего шлюза.
  Не используйте значение по умолчанию `phone100` для разных пользователей.
- В producer задайте **тот же** `AGENTCALL_PEER_ACCOUNT_REF`. Стабильный `peerRef`
  строится из account ID и подтверждённого номера; `peerLabel` содержит номер для интерфейса.
  Номер фиксируется до начала звонка. `callId` и lifecycle-события сохраняются.
  Старый call ID без номера нельзя сопоставлять с текущим номером назначения.
- Проверяйте пользовательскую изоляцию и реальный разговор после установки.
  Регистрация SIP или успешный HTTP-запрос сами по себе не доказывают работу звука.

### Контракт самостоятельного SMS-подключения

`POST /v1/sms/device-connect` принимает `device_id` и `display_name`; пользователя
определяет текущая авторизация сайта. Ответ возвращает `account_id`, `device_id`,
`server_url` и одноразово показанный `device_token`. Этот токен предназначен только
для APK `/agent/*`, не для UserIO API. Серверный `/v1/sms/agent-binding` доступен
только шлюзу и проверяет существование и права точной пары пользователя и SMS-аккаунта.
Удаление аккаунта запрещает новые операции; уже отправленные результаты сохраняются.
