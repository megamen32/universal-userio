## Точная оставшаяся граница

Для утверждения о восстановлении корневой сессии требуется её собственный
реальный hosted `accounts_list`: успех дочерней сессии его не заменяет.
Корневому владельцу передана одна такая проверка вместе с запросом сохранить
UTC-время, URL и request/operation ID отказа, если он повторится.

Если корневой hosted-вызов по-прежнему возвращает `UNAVAILABLE / Connection
failed`, а эти независимые вызовы успешны, следующий минимальный шаг —
сопоставить именно этот request/operation ID с trace внешней connector-платформы.
Такой trace и управление её транспортом не доступны через текущие инструменты;
не подтверждённый отказ не лечится перезапуском здорового UserIO.
Рабочий временный маршрут регистраций — уже проверенный прямой UserIO MCP;
не следует повторять принятые отправки/регистрации через него.
