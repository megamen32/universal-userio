# SMS: rooted S21 и APK для других Android

Собственный rooted S21 использует существующий SSH/Termux:API маршрут. Для SMS
на нём отдельный APK не нужен. Голосовые звонки сохраняют GSM2SIP/AgentCall.
Аккаунт и прежняя SMS-история сохраняются; операторская привязка этого телефона
в UserIO — `sms-native:default`.

Для нерутированного Android в списке SMS на сайте есть «Подключить SMS · скачать
APK». Прямая ссылка: [Android SMS Agent](https://msg.bezrabotnyi.com/sms-gateway/agent/download).
После установки разрешите SMS и работу приложения в фоне. В приложении задаются
URL шлюза и защищённый device Bearer вашей установки; токен не помещается в URL
скачивания. Общий операторский токен чужим пользователям не передаётся. Для своей
установки используйте [исходники шлюза](https://github.com/megamen32/android-sms-gateway).
Регистрация создаёт отдельный `sms:<device_id>` аккаунт. Сервер выбирает устройство
по его аккаунту; один номер собеседника на двух телефонах не смешивает диалоги.

Для APK отправка идёт с точным `device_id` и ключом идемпотентности черновика.
Для rooted S21 `device_id` опускается. Ответ `queued_for_device` означает очередь,
а не доставку получателю. Статус `sent` подтверждает Android callback/запись в
отправленных, но не подтверждает получение адресатом. Неизвестный исход не
повторяется автоматически. Старые receipts и SMS не пересылаются при восстановлении.

Режим скрытности меняет отметки просмотра в UserIO; SMS не получает выдуманную
провайдерскую квитанцию прочтения. ИИ-черновики сохраняют явное подтверждение,
а собственный текст пользователя отправляется обычной кнопкой отправки.

История собственного S21 берётся из системного SMS-хранилища, включая входящие
и отправленные сообщения, через защищённый `GET /v1/history`. Стабильные Android
ID, исходные даты и номера/короткие адреса сохраняются. Начальный снимок поступает
как история: он не запускает ИИ и не меняет прочтение на телефоне. Последующие
сообщения импортируются по сохранённому ID; повторное чтение не создаёт дублей.
Исходящая SMS с доказанной связью с прежним receipt заменяет показ карточки
подтверждённого черновика; две реально разные SMS с одинаковым текстом сохраняются.

GSM2SIP на этом же S21 обслуживает звонки и SIP MESSAGE для новых SMS/отправки и
статусов. Его текущий журнал трафика и очищаемые очереди не являются полным архивом
Android; remote API чтения всего архива в установленной версии нет. Полная история
читается через существующий native маршрут без второго APK или фонового агента
на телефоне. APK-подключения предназначены для других устройств; отключённые
подключения не отображаются как активные аккаунты. Список диалогов отдельного
SMS-аккаунта фильтруется по его точной привязке, а не по всему каналу SMS.
