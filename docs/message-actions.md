# Сообщения и безопасные действия UserIO

Для текста в готовый чат и для первого сообщения новому контакту используйте
`userio.messages.prepare`: передайте `conversation_id` либо `account_ref` и
`identifier`, а также `text` и постоянный `request_id`. Новый контакт сначала
разрешается в точного получателя; затем сохраняется обычный черновик.
Для отправки подтвердите этот черновик через `userio.draft.approve_send`.
`contacts.resolve` отдельно проверяет получателя без подготовки сообщения.
HTTP: `POST /v1/messages/prepare` с теми же полями. Это единственный публичный
маршрут подготовки переданного текста; старые draft/create, channel/send_draft
и contact/start API удалены. Нажатие человеком «Отправить» в веб-интерфейсе
явно подтверждает точный текст и использует тот же durable approval executor.

Реакции Telegram, их снятие (`emoji: ""`) и индикатор набора (`typing`,
`active:true/false`) доступны через `userio.messenger.safe_action` без отдельного
approval. Они используют точный аккаунт, чат, исходное сообщение и `request_id`;
не отправляют текст и не отмечают сообщения прочитанными. Индикатор не применяется
к broadcast-каналам. Начало и остановка набора — разные запросы с разными request_id.
