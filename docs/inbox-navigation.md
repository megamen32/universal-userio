# Новый интерфейс UserIO

Рабочий сайт: https://msg.bezrabotnyi.com/ . Обновите страницу, чтобы загрузить
новый интерфейс. Слева находится компактная панель каналов. Нажатие на канал
открывает список его аккаунтов; можно выбрать отдельный аккаунт или общую ленту.
Выбор сохраняется при повторном открытии списка аккаунтов.

Над переписками доступны «Все», «Непрочитанные» и «Личные». Кнопка «Папки»
раскрывает боковую панель. Через «Создать папку» можно выбрать переписки из
разных каналов, затем изменить состав, переименовать или удалить папку.
Удаление папки сохраняет сами переписки. Поиск в редакторе находит также
старые переписки; сохранённая папка загружает свои чаты независимо от последних
100 чатов общей ленты. Поиск сообщений остаётся общим; выбор папки очищает поиск.

Свои папки сохраняются в этом браузере, включая перезагрузку и новый вход.
Они не синхронизируются между устройствами. Доступно до64папок по100переписок.
Настройки чтения, права, свой ИИ и выход доступны через шестерёнку.
Кнопка солнца/луны переключает тему. Новая установка открывается в тёмной теме;
ранее сохранённый выбор темы сохраняется. Подключение аккаунтов, отправка,
изображения и скачивание используют прежние рабочие пути.

Код: `web/universal-userio-web/src/components/inbox-navigation.tsx`,
`inbox-folders.ts`, интеграция в `App.tsx`. HTTP `GET /v1/conversations` принимает
необязательный `conversation_ids` — до100уникальных IDs через запятую.
Проверка чтения и граница пользователя сохраняются; пустой/некорректный фильтр
отклоняется. Запрос только читает БД, не отмечает сообщения прочитанными и
не обращается к провайдеру. Миграции БД не требуется.

Принято15.10.2026: настоящий browser44,1280px desktop и320/390px mobile,
два Telegram аккаунта, папка MAX+почта, reload/rename/delete, реальные прежние
file/image downloads с точными SHA256. Повторных отправок или звонков не было.
