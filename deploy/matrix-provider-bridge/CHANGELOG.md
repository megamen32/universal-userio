# История изменений

## 2026-10-14

- Matrix Application Service для личных аккаунтов MAX и VK через UserIO.
- Отдельные пространства и комнаты диалогов/групп; исключение каналов.
- Двусторонняя передача текста, изображений и файлов до 2 МиБ.
- Нативные подтверждения доставки, постоянные привязки и защита от повторных транзакций.
- Восстановление подтверждённой отправки после перезапуска без повторной загрузки файла.
- Защита от обратной отправки импортированных вложений, включая старые события.
- Сохранение исходного изображения человека после получения нативного эха.
- Повтор чтения свежего вложения MAX при задержке метаданных.
- Обновление отклонённого слота загрузки VK без повторной доставки сообщения.
- Русское руководство установки, пример регистрации Matrix, MIT для компонента и CI.
