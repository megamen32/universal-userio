# Участие в разработке

Этот каталог содержит Matrix Application Service для MAX/VK через UserIO.
Предложения и ошибки принимаются в [Issues](https://github.com/megamen32/universal-userio/issues),
изменения — через pull request в `main`.

Для ошибки укажите версии Python, UserIO и homeserver, направление передачи,
тип сообщения, ожидаемый результат и шаги воспроизведения. Удалите токены,
содержимое переписок, личные ID и подписанные ссылки на вложения из примеров и журналов.
Проблемы с раскрытием секретов сообщайте через приватный способ связи владельца
из его GitHub-профиля; секреты не публикуйте в Issues.

Перед PR выполните `python3 -m unittest -v test_bridge` из этого каталога
(fast unit: ожидаемые 10 секунд, максимум 30 секунд).
Описывайте проблему, изменение поведения и проверку по-русски.
Изменения провайдерного транспорта размещаются в `src/universal_userio/`
и требуют соответствующей проверки UserIO.

Для изменений доставки используйте focused integration с перепиской с собой:
текст, PNG и файл в обе стороны, нативный receipt и повтор того же Matrix event.
Общий обычный прогон вместе с подготовкой ограничен 180 секундами.
Не отправляйте тестовые сообщения чужим контактам без отдельного разрешения.
Не повторяйте отправку автоматически при неизвестном исходе и сохраняйте
совместимость SQLite-привязок, стабильных request ID и маркеров импортированных событий.

Новые внешние зависимости и изменения формата конфигурации объясните в PR.
Проверьте конечный бюджет процесса и обновите README при изменении ограничений.
Вклад в перечисленные в README файлы этого компонента предоставляется под MIT.
